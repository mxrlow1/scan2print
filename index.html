Units of the file

Auto: GLB/GLTF are metres; tiny models (< 3 units) are treated as metres; everything else as mm. Changing this re-scales the current model.

Formats: OBJ, GLB, GLTF (+.bin, select all files), PLY (mesh), STL, or a .zip containing one of those. Textures/colours are ignored — printing only needs the shape. Files never leave your phone.

Scan → print guide

iPhone 16 Pro Max (LiDAR)

Scaniverse (free): tap + → Mesh (not Splat) → choose Small/Medium object → walk slowly around the object in 2–3 rings (low, middle, top-down) → Done → process with Detail. Then Share → Export model → pick OBJ, STL, GLB or PLY → Save to Files.

Polycam: use LiDAR mode for bigger things (furniture, rooms, parts > ~15 cm) or Photo mode for small detailed objects (upload 20–200 photos). Export → choose GLB/OBJ/STL (some formats need a paid plan — GLB is usually available) → Save to Files.

KIRI Engine: Photo Scan or Featureless Object mode works well for small matte items; export OBJ/STL/GLB.

Then in Scan2Print tap Open 3D file and pick the file in Files (a .zip from the app is fine too).

Samsung Galaxy S26 Ultra (photo-based)

  • No LiDAR, so use photogrammetry apps: KIRI Engine, Polycam (Photo mode), Scaniverse or RealityScan.
  • Use soft, even light (overcast daylight / no harsh shadows). Avoid shiny, transparent and plain black or white surfaces — a light dusting of scanning spray or dry shampoo helps.
  • Put the object on a textured surface (newspaper) and move the phone, not the object. Take 40–100+ sharp photos with 60–80 % overlap in 3 rings at different heights.
  • Lock focus/exposure if the app allows it and fill the frame with the object.
  • Export OBJ/GLB/STL, then open it here (installed as an app, you can also Share the file straight to Scan2Print).

Typical fix-up order

  1. Open → check the size (units). Scan apps export metres; Scan2Print converts to mm.
  2. Cut away the floor/table, or use Flatten bottom.
  3. Repair → Remove floating pieces → Fill holes → (optional) Smooth → Simplify big scans to ~100–300k triangles.
  4. Size → set the exact height/width you want, Lay flat on its best face.
  5. Export STL (or 3MF) and open it in your slicer. Aim for “Watertight ✓”.

Install as an app

iPhone Safari: Share → Add to Home Screen. Android Chrome: ⋮ → Install app. Works offline after the first visit.

Everything runs on your device — no uploads. Undo/redo keeps the last ~20 steps.
